NumPy: массивы, broadcasting, векторизация

10 мин АЛАртем Лебедевич 10 ноября 2026

NumPy — фундамент всего научного Python: pandas, scikit-learn, PyTorch и JAX наследуют его модель массива. Чтобы писать быстрый код и понимать чужие ошибки формы («operands could not be broadcast together»), нужно знать три вещи: как массив лежит в памяти, как работает broadcasting и как заменить цикл операцией над целым массивом. Линейная алгебра, на которой всё держится, разобрана в главе Векторы и матрицы.

Модель памяти: shape, dtype, strides

ndarray — один непрерывный блок памяти плюс метаданные: dtype (тип элемента), shape (размеры) и strides (на сколько байт сдвигаться, чтобы перейти к следующему элементу по каждой оси). Многомерность — только способ интерпретации плоского буфера.

python
import numpy as np

a = np.arange(12, dtype=np.float32).reshape(3, 4)
print(a.shape, a.dtype, a.strides, a.flags["C_CONTIGUOUS"])
# (3, 4) float32 (16, 4) True
t = a.T
print(t.shape, t.strides, t.flags["C_CONTIGUOUS"])
# (4, 3) (4, 16) False

Строка из 4 float32 занимает 16 байт, поэтому шаг по оси 0 — 16, по оси 1 — 4. Транспонирование ничего не копирует: оно лишь переставляет strides ((4, 16)), и массив перестаёт быть C-непрерывным. Операции над некоторыми срезами и reshape после транспонирования могут из-за этого сделать копию.

View или copy. Базовые срезы (a[:2], a[:, ::2], a.T, reshape в большинстве случаев) возвращают view — другой взгляд на те же данные; запись в него меняет оригинал. «Продвинутая» индексация (списком индексов, булевой маской) возвращает copy.

python
v = a[:, ::2]
v[0, 0] = 100
print(a[0, 0], np.shares_memory(a, v))   # 100.0 True — оригинал изменён
c = a[[0, 1]]                             # fancy indexing → копия
print(c.base is None)                     # True: своя память

Ловушка

Функцию, которая получила массив и меняет его на месте (x -= x.mean()), вызывающий код не ждёт. Если нужна независимость — x.copy(); проверить связь — np.shares_memory(a, b).

Broadcasting

Чтобы сложить массивы разных форм, NumPy выравнивает их формы по правому краю, и для каждой пары размеров должно выполняться: размеры равны, или один из них равен 1 (тогда он «растягивается» без копирования), или у одного массива этой оси нет (считается 1). Результат — поэлементный максимум размеров.

text
a:       (8, 1, 5)
b:          (3, 1)     →  выравниваем справа: (1, 3, 1)
результат:  (8, 3, 5)
python
print((np.ones((8, 1, 5)) + np.ones((3, 1))).shape)   # (8, 3, 5)
X = np.arange(6).reshape(3, 2)          # [[0 1] [2 3] [4 5]]
print(X - X.mean(axis=0))               # (3,2) - (2,) → центрирование столбцов

Несовместимая пара, например (3, 2) и (3,): справа выравниваются 2 и 3 — не равны и не 1, ошибка. Лечится явной осью: v[:, None] превращает (3,) в (3, 1). Типичные применения: центрирование и стандартизация признаков, матрица попарных разностей (x[:, None] - x[None, :]), маски внимания.

Оси

axis=k означает «схлопнуть ось k». Для X формы (3, 2): X.sum(axis=0) → [6 9] (по строкам, сумма столбцов), X.sum(axis=1) → [1 5 9]. С keepdims=True форма сохраняет ось размера 1 ((1, 2)), и результат можно сразу вычесть из X через broadcasting — привычка, которая убирает половину ошибок формы. Те же правила у mean, std, max, argmax, softmax.

Индексирование

python
a = np.arange(12, dtype=np.float32).reshape(3, 4)
print(a[a > 5], a[a > 5].shape)         # [ 6.  7.  8.  9. 10. 11.] (6,) — копия, одномерная
a[a > 5] = 0                            # запись по маске работает на месте
idx = np.array([2, 0])
print(a[idx, 1])                        # элементы (2,1) и (0,1)

Маска имеет форму массива (или его первых осей), результат — одномерный: порядок элементов сохраняется, форма теряется. Для «по строке взять индексы из другой матрицы» используйте np.take_along_axis.

Векторизация: от цикла к матричному произведению

Цикл for по строкам выполняется в интерпретаторе, а A @ B — в оптимизированной BLAS. Задача: найти k ближайших векторов по косинусной близости для батча запросов.

python
rng = np.random.default_rng(0)
A = rng.normal(size=(1000, 64)).astype(np.float32)   # корпус
Q = rng.normal(size=(5, 64)).astype(np.float32)      # запросы

# евклидовы расстояния: ||q-a||² = ||q||² − 2 q·a + ||a||²
d2 = (Q**2).sum(1)[:, None] - 2 * Q @ A.T + (A**2).sum(1)[None, :]
d2_naive = ((Q[:, None, :] - A[None, :, :]) ** 2).sum(-1)   # (5, 1000, 64) в памяти
print(d2.shape, np.abs(d2 - d2_naive).max() < 1e-3)         # (5, 1000) True

# косинус: нормируем, дальше — просто скалярные произведения
An = A / np.linalg.norm(A, axis=1, keepdims=True)
Qn = Q / np.linalg.norm(Q, axis=1, keepdims=True)
S = Qn @ An.T                                                # (5, 1000)

k = 3
idx = np.argpartition(-S, k, axis=1)[:, :k]                  # k лучших, но неупорядоченно, O(N)
order = np.argsort(-np.take_along_axis(S, idx, 1), axis=1)   # сортируем только k штук
top = np.take_along_axis(idx, order, 1)
print(top.shape, top[0])                                     # (5, 3) [ 51 960 378]
print(np.allclose(top, np.argsort(-S, axis=1)[:, :k]))       # True

Идея: argpartition делает частичную сортировку за O(N) на строку вместо полной за O(N\log N) — это стандартный приём top-k (в точном поиске ближайших соседей, см. векторные индексы). Наивная версия через Q[:, None, :] - A[None, :, :] материализует тензор (5, 1000, 64): на реальных размерах он не поместится в память, поэтому формула с матричным произведением — не оптимизация, а необходимость. Скорость на вашей машине проверьте %timeit; относительно цикла по запросам выигрыш обычно в десятки раз, но числа зависят от железа и размеров.

einsum

np.einsum записывает контракцию индексов строкой: повторяющийся индекс суммируется, индексы после -> остаются.

python
S2 = np.einsum("qd,nd->qn", Qn, An)       # то же, что Qn @ An.T
print(np.allclose(S, S2, atol=1e-6))      # True
# скалярное произведение каждой пары строк:  np.einsum("nd,nd->n", X, Y)
# батч матричных произведений:               np.einsum("bij,bjk->bik", A, B)

Когда читаемость выше (внимание, батчи, тензоры), einsum понятнее цепочки transpose/reshape; для обычного умножения матриц @ быстрее и проще.

Ловушки dtype

python
print(np.array([100], dtype=np.int8) + np.int8(100))        # [-56] — переполнение без ошибки
print(np.float32(16777216) + np.float32(1))                  # 1.6777216e+07 — +1 потерялся
print(np.float64(16777216) + 1)                              # 16777217.0
print(np.arange(5).dtype, (np.arange(3) / 2).dtype)          # int64 float64

Целые типы NumPy переполняются молча (оборачиваются по модулю); float32 имеет ~7 десятичных разрядов, и сумма миллионов слагаемых копит ошибку (суммирование NumPy попарное и сглаживает, но не отменяет её). В NumPy 2 приведение типов подчиняется NEP 50: результат float32_array + python_float остаётся float32 (Python-скаляр «слабый»), а float32_array + np.float64(...) — уже float64.

Случайные числа

Современный API — Generator, а не np.random.seed с глобальным состоянием:

python
g = np.random.default_rng(42)
print(g.integers(0, 10, 5), g.normal(size=2).round(3))   # [0 7 6 4 4] [ 0.941 -1.951]
child_a, child_b = np.random.SeedSequence(1).spawn(2)    # независимые потоки для воркеров
rng_a, rng_b = np.random.default_rng(child_a), np.random.default_rng(child_b)

Передавайте rng в функцию явно — воспроизводимость не зависит от порядка вызовов в чужом коде. Для параллельных процессов сидируйте через SeedSequence.spawn, а не seed + i (потоки с соседними сидами не гарантированно независимы). Подробнее о воспроизводимости — в главе Воспроизводимость и трекинг.

Ловушки

  • Бессознательная мутация view: правите срез — меняется исходный массив.
  • A * B — поэлементное умножение, A @ B — матричное; np.dot для ≥3-мерных ведёт себя неочевидно, используйте @/matmul.
  • Форма (n,) против (n, 1): (n,) - (n, 1) даёт (n, n), а не (n,). Это самый частый «тихий» баг broadcasting'а: ошибки нет, форма не та, а метрика странная.
  • Цикл по строкам или np.vectorize (это всё ещё цикл Python) вместо матричной операции.
  • np.mean по пустому массиву даёт nan с предупреждением; == для float вместо np.isclose.
  • На собеседованиях: объяснить broadcasting на примере; реализовать softmax/стандартизацию/попарные расстояния без циклов; найти top-k без полной сортировки; чем view отличается от copy; почему int8 переполняется; как посчитать accuracy одной строкой ((y_pred == y_true).mean()).

Проверь себя

Какая форма у результата `np.ones((4, 1, 3)) * np.ones((5, 1))`?

Выравниваем справа: (4, 1, 3) и (1, 5, 1) → (4, 5, 3).

Почему `x = a[:, 0]; x += 1` меняет `a`, а `x = a[[0, 1], 0]; x += 1` — нет?

Базовый срез — view на те же данные, индексирование списком (fancy indexing) — копия.

Как найти 10 наибольших элементов в массиве из $10^7$ чисел и зачем не `sort`?

np.argpartition(-x, 10)[:10], затем отсортировать эти 10. Частичная сортировка O(N) вместо O(N\log N).

Чему равны `X.sum(axis=0)` и `X.sum(axis=1)` для `X` формы `(3, 2)` и какие у них формы?

axis=0 схлопывает строки: форма (2,); axis=1 схлопывает столбцы: форма (3,). Ось, указанная в axis, из формы исчезает.

Как векторизованно посчитать матрицу косинусных близостей для двух наборов векторов?

Нормировать строки (/ np.linalg.norm(..., axis=1, keepdims=True)) и умножить Qn @ An.T. Матрица (n_q, n_a).
