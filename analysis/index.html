Требования и моделирование

  • User stories и use cases, критерии приёмки

Данные

API и интеграции

  • REST: ресурсы, методы, коды ответов, ошибки, версионирование, безопасность

  • SOAP, gRPC, GraphQL: чем отличаются и когда что использовать

Очереди и архитектура

  • Очереди и брокеры сообщений: Kafka, RabbitMQ
